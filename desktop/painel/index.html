Conta do administrador

O sistema está vazio. Crie a conta com que você vai entrar. Lá dentro, em Configurações → Equipe, você cadastra os donos, a recepção e os professores.

Acesso pelo celular e outros PCs

Com o celular no mesmo Wi-Fi, aponte a câmera para o código. No navegador, use Adicionar à tela inicial.

    Sem rede agora

    O sistema funciona normalmente neste computador — é só usar Abrir o sistema. Quando o notebook entrar no Wi-Fi, o endereço e o QR code aparecem aqui sozinhos.

    Backup

    Automático todo dia depois das 3h. Guarda 7 diários, 4 semanais e 12 mensais. Copie o mais recente para um pendrive uma vez por semana.
